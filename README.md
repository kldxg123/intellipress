# IntelliPress · 数字孪生可信医疗推理演示系统

AI 驱动的高血压智能早筛与个性化干预系统的交互式演示站。以患者旅程为主线，展示"数字孪生 × 大模型辅助的可信医疗推理"全闭环。

## 演示流程（六阶段）

1. **初诊建档** — 本地 LLM 病历语义解析，非结构化病历 → 结构化健康档案
2. **智能早筛** — 《中国高血压防治指南（2024 年修订版）》规则引擎 + 医学知识图谱作出风险分层判定，大模型仅负责解释（DeepSeek 实时推理）
3. **孪生推演** — China-PAR 简化校准模型 what-if 推演："未干预 vs 规范干预"五年双轨迹，附计算口径与依据面板
4. **个性方案** — 临床路径规则引擎按分层结论生成五维度个体化方案（用药/膳食/运动/监测/复诊）
5. **居家执行** — 照护任务时间轴 + 24h 监护时钟压缩演示 + 突发情景分级响应（Ⅳ→Ⅰ）
6. **复盘迭代** — TTR 复盘、医师边界内参数更新（≤10%）、联邦学习

## 可信设计

- 医学判断主体为**指南规则引擎 + 知识图谱**，大模型仅解释不参与判定
- **文献证据库 71 篇**（大模型×高血压 13 / 数字孪生 4 / 真实数据 15 / 数据统计 4 / 生活方式与综合管理 35），经「证据支持」边挂接知识图谱节点，阶段 2 图谱节点带证据角标、下方附按分类分组的证据文献列表
- 每个数字带**溯源标签**：实测 / 孪生 / 规则 / 模型
- 风险概率由透明模型运行时计算，界面附公式、输入来源与局限性声明

## 技术栈

React + TypeScript + Vite + Tailwind CSS + three.js（3D 数字孪生背景）+ DeepSeek API（dev 代理注入密钥）

## 本地运行

```bash
npm install
# 如需第 2 阶段真实推理，创建 .env.local（不会入库）：
# DEEPSEEK_API_KEY=sk-xxx
npm run dev
```

无 `.env.local` 时第 2 阶段自动进入回放兜底模式，演示不受影响。

## 验证

`scripts/` 内含规则引擎、风险模型、方案引擎的单测（`test-*.mjs`）与 puppeteer 端到端走查脚本（`verify-*.mjs`）。
